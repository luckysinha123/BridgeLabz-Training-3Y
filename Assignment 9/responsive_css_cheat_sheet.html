Responsive CSS Cheat Sheet

Filters

Apply graphical effects like blur or color shift.

filter: grayscale(100%);

Media Queries

Apply CSS rules based on device characteristics like width.

@media (max-width: 700px) { ... }

Flexbox

1D layout model for alignment and space distribution.

display: flex; justify-content: center;

CSS Grid

2D layout system for rows and columns.

display: grid; grid-template-columns: 1fr 1fr;

Typography

Fluid typography scaling dynamically.

font-size: clamp(1rem, 2vw, 2rem);

Viewport Units

Sizing relative to the viewport.

width: 100vw; height: 100vh;
