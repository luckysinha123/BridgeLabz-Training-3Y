Box-Sizing Comparison

The content-box (default) calculates the total width by adding width + padding + border. The border-box calculates the total width as exactly the specified width (padding and border are included inside).

content-box

Width: 300px
Padding: 30px
Border: 10px

Total Width: 380px

border-box

Width: 300px
Padding: 30px
Border: 10px

Total Width: 300px
