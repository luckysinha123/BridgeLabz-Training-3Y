1. What prerequisites are required for this Full Stack program? ▾

Basic knowledge of computers and logical problem-solving. No advanced coding background is required as we begin from basic JavaScript fundamentals.

2. How does the JavaScript Event Loop work? ▾

The Event Loop coordinates the Call Stack, Microtask Queue (Promises), and Macrotask Queue (setTimeout). Microtasks are always drained before macrotasks.

3. What is the difference between let, const, and var? ▾

var is function-scoped and hoisted with undefined. let and const are block-scoped and live in the Temporal Dead Zone until initialized.

4. Why should we use jQuery event delegation? ▾

Event delegation attaches a single event handler to a parent element rather than attaching hundreds to child elements, enhancing memory performance and supporting dynamically created elements.
